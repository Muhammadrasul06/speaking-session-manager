# Speaking Session Manager

Web app for an English teacher and students:

- Students sign in, browse open sessions, pick one time slot, and track bookings.
- The first account becomes Super Admin. Super Admin can promote any user to Admin or demote them back.
- Admins create sessions (any working hours and test length), open or close bookings, start a test manually, enter a score, and end the test.
- Students never see scores.

Sign in with email and password, or Google / X.

This repository is the source used by the Grok app preview. Hosting on Vercel is done from the Grok publish button (free), not from a paid Vercel plugin.
